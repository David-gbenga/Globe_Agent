# Procurement and Vendors

**Effective:** 2026-01-15 | **Owner:** Procurement

## When procurement is required

Any commitment to an external supplier above GBP 1,000 per year, and any
software or SaaS purchase at any value.

Expensing a subscription on a personal or corporate card to avoid procurement
is a policy breach, not a shortcut.

## Thresholds

| Annual contract value (GBP) | Process |
|---|---|
| Under 1,000 | Expense claim, no procurement involvement |
| 1,000 – 25,000 | Single quote plus procurement review |
| 25,001 – 100,000 | Three quotes, procurement-led |
| Above 100,000 | Competitive tender, Legal and CFO sign-off |

## Software and SaaS

All software purchases require a security review before signature, regardless
of value, including free tiers that process company data.

## Data processing

Any vendor handling personal data needs a data processing agreement in place
before go-live. Procurement holds the template.

## Existing vendors

Check the approved vendor list before sourcing. Adding a line to an existing
contract is usually faster than a new agreement.
